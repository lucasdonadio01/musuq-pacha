# Musuq Pacha

La página principal es el mapa interactivo del territorio y sus pueblos.

- `/`: mapa 3D, árboles, fauna, accesibilidad y sonido.
- `/simbolos/`: generador de símbolos original, conservado como micrositio y enlazado desde el footer.

Sitio estático, sin compilación. Para probar: `python -m http.server 8766` y abrir `http://localhost:8766/`.

Publicación: https://lucasdonadio01.github.io/musuq-pacha/

Los archivos Blender y los documentos de trabajo no se incluyen en la publicación.
