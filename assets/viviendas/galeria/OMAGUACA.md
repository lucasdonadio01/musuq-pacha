# Referencias de la aldea Omaguaca

- `omaguaca-foto.png`, `omaguaca-aldea.png` y `omaguaca-casa.png`: imágenes aportadas por el usuario como referencia visual. No se asigna una autoría ni una localización arqueológica no verificadas. Las referencias no implican una licencia de reutilización de terceros.
- `omaguaca-exterior-3d.png` y `omaguaca-interior-3d.png`: renders del modelo original realizado en Blender para Musuq Pacha.

El conjunto representa una interpretación artística de las referencias, no una reconstrucción arqueológica exacta. La terraza escenográfica agrega cuatro celdas sin reemplazar otras zonas; no altera el polígono geográfico fuente.
