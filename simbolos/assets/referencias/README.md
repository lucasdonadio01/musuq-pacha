Los nombres de carpeta siguen las agrupaciones de Figma. La interfaz aclara que kolla no equivale a Omaguaca y que las referencias ranqueles son regionales, no piezas querandíes verificadas. La bolsa tampoco se atribuye específicamente al pueblo qom. No se atribuyen significados culturales a los módulos inventados para la interacción.
